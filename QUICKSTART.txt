Fwpc - Quick Start

Windows 10 or 11 x64

1. Extract the full release ZIP into a local folder.
2. Open WiFiPhoneControl.exe.

USB direct
1. Enable Developer options and USB debugging on the phone.
2. Connect the phone with a USB data cable.
3. Select Start USB control. Approve USB debugging on the phone if prompted.
4. If several phones appear, select the one you want to control.

Wi-Fi (Android 11 or newer)
1. Connect the phone and PC to a local network where they can reach each other.
2. On the phone, open Developer options > Wireless debugging.
3. Select Pair device with pairing code and keep the dialog open.
4. In Fwpc, select Connect phone. Enter the address and six-digit code from the dialog.
5. When the phone is connected, select Start control.

If pairing succeeds but discovery fails, use Enter connection address. Enter the
current IP address and port from the main Wireless debugging screen on the phone.
Use Diagnostics for additional details. USB direct is available when the network
blocks communication between the phone and PC.

The ZIP includes scrcpy 4.0, ADB 37.0.0 and their runtime files. If the app reports
an incomplete release, extract the full ZIP again.
